## Hard rules

- **`assets/source/**` is read-only.** Never overwrite, crop, re-encode, rename,
  or delete the original frames, reference image, contact sheet, or GIF.
- **`frame_01.png` is the identity authority.** `frame_10.png` is byte-identical
  to it; preserve that.
- **Never present the cross-fade as a finished seamless animation.** Stage 1 is
  a preview. The final target is a layered rig with fixed face geometry.
- **No pixel art, Minecraft style, 3D reconstruction, or character redesign.**
- **No visible UI** (navigation, buttons, labels, footers, social icons). The
  page contains only the character. Debug switches stay in URL parameters.
- **No whole-image translate/rotate/scale** to fake hair motion or blinking.
- **Do not regenerate the face** with AI to “fix” frame differences.
- **Do not push `.github/workflows/**`.** The user's PAT lacks `workflow` scope;
  GitHub will reject it. Optional workflow YAML lives in `deploy/github-actions/`.
- **Do not run `npm run deploy`** (public publishing) without the owner's approval.
- **Keep `npm run build` and `npm run typecheck` green.**
- **Update `docs/` and `CHANGELOG.md`** whenever behavior changes.
- **Be honest about limitations.** “Not verified” must never be written as “done”.

## Current state

- Vite 8 + React 19 + TypeScript 7; Canvas 2D player.
- Ten key poses, 2300 ms loop, cross-fade near each key time.
- Immutable source assets; WebP derivatives generated by `scripts/optimize_assets.py`.
- Responsive dark stage, reduced-motion support, URL debug switches.
- Live at <https://fknejdcwnfi.github.io/website/> from the `gh-pages` branch.
- No layer extraction, mesh rig, eyelid layer, or automated visual regression yet.

## Delivery checklist

- One PR, one concern.
- Include commands run, screenshots (or why they were impossible), and known limitations.
- Update `CHANGELOG.md` and affected docs.
- Never merge your own PR; wait for the owner.

If blocked, stop and report:

```text
STOPPED: <one-line reason>
Done: <...>
Not done: <...>
```
