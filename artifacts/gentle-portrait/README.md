# 持續微風與無框圓形像素肖像

這是本輪12秒持續微風、24秒獨立眨眼的實際網站驗證。前版2300ms快速陣風證據仍保留在 [pixel-world](../pixel-world/README.md)，不以舊量測替代本輪結果。

- [圓形動態預覽](animation_preview.gif)：完整24秒聯合週期，兩輪微風與三次獨立眨眼；每40ms由瀏覽器實際截取256px圓形viewport，600張真實樣本，編碼後仍600幀，共24,000ms、19,743,368 bytes。
- [全部實際Canvas畫面](gallery.html)、[144格總覽](contact_sheet_144.png)、[身份／風動／眨眼對照](comparison.png)。圖集顯示原始256²邏輯Canvas，圓形展示由CSS裁切，沒有更改canonical母版。
- [擷取清冊](capture.json)、[逐時刻映射](frames/manifest.json)：完整24秒每100ms取樣，三個眨眼窗口再每10ms細化；327個時間樣本加10個參考姿態與10個連續風錨點，依SHA-256去重保存216張PNG（11,223,350 bytes），保留所有時刻映射。
- [完整網站與手機](../personal-site/README.md)：中軸圓形主視覺、Minecraft像素UI、無JS與故障時的同形備援。

## 行為驗證

[肖像QA](qa.json) **55項通過**：24個500ms窗口都有真實發絲／耳環像素變化，最少285像素；長卷髮峰約6.84／7.46邏輯像素，八組髮束與左右耳環均有可見參與。27,519個保護像素與160個髮根保持固定，眼瞼只改原眼區，零內部破洞，固定42色與Canvas二值alpha保持不變。

完整rig的lag／trail／wake都跨週期取樣；風循環前後的變形位置、速度與像素差分無重置跳變。100輪風×13相位逐像素一致。60／120／144／240Hz模擬rAF在相同13時刻得到相同像素，涵蓋眨眼開合與風／眨眼跨週期；這是時鐘與像素確定性測試，不是實體螢幕FPS。

眨眼有獨立24秒時鐘，開始時間4400／11300／20300ms，相鄰間隔6.9／9.0／8.1秒。單次100ms閉合、20ms停留、160ms重開，期間頭髮繼續飄動。正常起點是微風中的自然幀；明確pose1／10及減少動態顯示完整canonical靜止角色。wind=0只停止髮絲與耳環風動，獨立眨眼仍繼續。

[整站QA](../personal-site/checks.json) **65項通過**：四種寬度、DPR1／2、圓形居中、透明無框、整數物理像素倍率與起點、鍵盤／真實內容、離屏續播、無JS及六種故障備援。桌機512CSSpx與手機256CSSpx均精確居中；DPR1對應2×／1×，DPR2對應4×／2×實體像素倍率。CSS圓形邊緣抗鋸齒不等於Canvas內部色彩平滑。

## 實際效能

[完整量測](performance.json)：production單頁headless Chromium，1200×1000、DPR1、無CPU節流；先穩定2500ms，再取樣完整12000ms微風週期，期間無截圖或其他瀏覽器工作。

| 排程 | 實際Canvas繪製 | callback中位數／p95 |
| --- | --- | --- |
| 原生容器排程 | 12.003秒721次，約60.07次／秒 | 3.9／5.2ms |
| 關閉Chromium幀率限制 | 12.004秒3263次，約271.82次／秒 | 3.5／4.0ms |

整個風週期均活動，沒有前版靜止段拉高吞吐量；另分三等份記錄相位差異。兩次量測均無超過50ms長任務、正常頁面JS或HTTP錯誤。不限幀測試是容器吞吐量，GPU／合成器／作業系統及實體120／144／240Hz顯示器未量測，不宣稱所有裝置都達到此數值。

證據不進入 `dist/`，網站持續使用精簡程序式renderer與原有runtime素材，不下載幾百張動畫圖。
