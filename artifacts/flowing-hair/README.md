# 圓形內持續飄動的髮束

這一輪只細化頭髮的柔韌、分層與可見度，保留PR7已確認的12秒連續風場、24秒獨立眨眼及圓形居中展示。沒有改角色母版、臉、眨眼時序、網站版面或DPR像素對齊。

先看[完整24秒圓形動態](animation_preview.gif)，再看[手機原尺寸兩秒對照](circle_mobile_two_seconds.png)與[桌面兩秒對照](circle_desktop_two_seconds.png)。兩秒對照分別由實際256／512 CSS像素的網站viewport截取；不使用整張人物平移、旋轉或縮放來冒充髮絲運動。

## 可見性與安全

[本輪肖像QA](qa.json) **58項通過**，其中包含圓形範圍內排除眼區的髮束檢查。[上一版本baseline](baseline-circle.json)於改動前量測，保留來源commit與相同256²圓形遮罩定義。上版已有持續動態；差分數量不能單獨當成柔順或美觀的證明。

| 指標（邏輯像素／實際像素數） | PR7 baseline | 本輪 |
| --- | ---: | ---: |
| 圓形內0→2秒變化像素（排除眼區） | 3,204 | 5,426 |
| 24個500ms窗口中最少變化像素 | 258 | 669 |
| 24個2秒窗口中最少變化像素 | 1,052 | 2,030 |

中段／臉側位移以實際rig的分層場與row曲線量測，限於圓形內；不是拿裁切外的自由尖端峰值替代。首列兩秒比較與中段峰值的完整取樣見JSON。所有八組髮束與兩條耳環都有實際像素變化，三次眨眼期間也持續有髮束變化。

27,519個保護像素與160個髮根保持不變，眼瞼差分只在原眼區；內部修復區零破洞，raw Canvas保留42色、二值alpha及nearest-neighbor。完整lag／trail／wake在12秒接縫的位移、速度和實際像素差分沒有重置；100輪×13相位逐像素一致。60／120／144／240Hz模擬rAF在相同13個時刻像素一致，這是計時檢查，不是實體螢幕FPS。

[整站QA](../personal-site/checks.json) **65項通過**，記錄的production主JS為 `index-uVMb2L7T.js`；桌機／手機、DPR1／2、圓形無框居中、實體像素倍率與起點、鍵盤、無JS及六種故障備援保持有效。完整頁面截圖見[personal-site](../personal-site/README.md)。

## 實際效能

[performance.json](performance.json)：production單頁headless Chromium，1200×1000、DPR1、無CPU節流；穩定2500ms後測完整12000ms風週期，量測期間無截圖或其他瀏覽器工作。

| 排程 | 實際Canvas繪製／秒 | callback中位數／p95 |
| --- | ---: | ---: |
| 原生容器排程 | 60.07 | 3.8／5.6ms |
| 關閉Chromium幀率限制 | 237.71 | 3.6／5.6ms |

兩次量測均無超過50ms長任務、正常頁面JS或HTTP錯誤。整個週期持續風動，沒有靜止段灌高吞吐量。不限幀結果是容器吞吐量，不能宣稱所有實體120／144／240Hz螢幕都達到相同FPS；GPU、合成器及使用者裝置仍會影響顯示結果。
