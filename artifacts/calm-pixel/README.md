# 暖白阅读、主题整理与独立复核

本轮以`64a3282da47053607cff600bbe57bcc27d692da7`为基线，直接整理现有主题。暖白实色、留白和较轻的边框借鉴简洁产品界面的阅读感；Minecraft暮色、像素字体／图标、7章节与原人物保留。具体实现见[指南](../../docs/guides/calm-pixel.md)。本目录只保存本轮报告与少量截图，不替代其他轮次证据。

## 实际范围

- 独立代码代理检查可选浏览器API、静态一致性与依赖；独立视觉代理逐张查看首页、作品、手记和手机截图。代理判断与实际自动化检查分别记录，不将截图当作动态证明。
- `npm run build`实际执行160项Node测试、strict TypeScript与生产构建；资源、18项仓库守卫测试、字体覆盖及响应式资源核对另行执行。
- Sites根路径与Pages `/website/`分别构建和浏览器验证。逐项数量、基础路径、报告文件与构建摘要由[verification.json](verification.json)记录；原始报告保留各自范围。
- [来源保留](source-preservation.json)核对160份源素材、冻结资料、原工程、公开资源和`poeticPixel`文件与基线逐字节一致；104份公开文件与构建逐字节一致。共享浏览器监听是本轮有意修复的边界，不包含在“不变”声明内。
- [可选媒体API复核](browser-signal-review.json)记录getter异常进入清理／旧式回退的可复现缺口及7项相关回归；不宣称它是已发生的访客漏洞。原CSP、资源发布清单和限制策略不放宽。

## 外观与性能

[首页](home.png)、[桌面作品](work.png)、[手机作品](mobile.png)、[手记](journal.png)展示本轮布局；手机作品的正文改为全宽，实际Chromium可访问树仍保留table、3列标题、3行和6单元格。无JS使用同一主题与原生阅读全文入口。

[产物比较](bundle-comparison.json)使用同一gzip方法：主CSS 75,084→76,321bytes，gzip 16,771→16,541bytes；主JS gzip 99,093→99,103bytes。移动阅读布局增加少量CSS，主题整理略减压缩体积；不将这些字节差称作显著网络提速。

[基线采样](performance-baseline.json)与[当前采样](performance-current.json)顺序独占Chromium，1440×1100／DPR1、稳定2秒后采样12秒。当前估计来源换帧49.78次／秒，回调中位4.6ms、p95 5.8ms；基线49.92次／秒、4.7／6.2ms。两次均无浏览器异常。单次本地观察只能说明这些条件下的连续播放，不能证明真实显示器FPS、访客CWV或稳定性能收益。

## 已记录的失败与限制

- 首次来源帧检查与多个浏览器并行时，320ms内只观察到4个来源帧，未达到既有5帧阈值；保留[失败记录](scene-concurrent-attempt.json)。没有降低阈值或修改人物，随后独占浏览器完整134项检查通过，结果见`root-scene.json`。
- npm audit官方端点返回`403 Forbidden`／`Domain forbidden`，本轮未完成npm audit，未尝试绕过或无限重试。正常GitHub官方公告接口对70个锁定精确版本查询全部成功、0命中，见[依赖报告](dependency-advisories.json)；这属于部分替代，不能保证未知漏洞不存在。
- 页面meta CSP不能设置托管服务控制的响应头；本轮没有声称已完成真实设备、物理输入法或访客网络测量。
- 本目录记录本地源码和构建验证。正式保存、部署及GitHub Pages结果须由对应平台返回确认，不能从本地截图推定。
