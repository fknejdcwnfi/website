# 參考原文（凍結）

這個目錄保存最初委託的兩份文件，**逐字保留**，不作為現行工作規格：

| 檔案 | 原始用途 |
| --- | --- |
| `10_frame_prompts.md` | 十幀的動作描述、英文增量 prompt、時間軸 |
| `codex_prompt.md` | 給 Codex CLI 的完整任務書（角色綁定、風、眨眼、驗收） |

## 為什麼保留

- 它們記錄了擁有者最初的意圖與視覺語言。
- 未來的代理或美術可以追溯「為什麼是這十幀」、「為什麼禁止 pixel art」。
- 改寫會讓原始決策消失；因此只凍結，不更新。
