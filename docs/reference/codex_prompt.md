# Codex CLI：原始動漫畫風的 10 幀風動＋眨眼網站動畫

你是一位資深前端圖形工程師及 2D Character Rigger。現在請在現有目錄中製作第一階段角色動畫。**暫時禁止像素化/Minecraft 化**，完整保留原畫風。

## 重要素材

- `frames/frame_01.png`：原始角色圖片，身份、外觀、構圖的**唯一最終權威**。
- `frames/frame_02.png` ~ `frames/frame_10.png`：風動與眨眼的 10 幀姿態參考；**這些不是逐像素完美匹配的動畫幀**。
- `10_frame_prompts.md`：每幀動作規格及時間軸。
- `10_frame_contact_sheet.jpg`、`10_frame_preview.gif`：視覺審核用，動圖是粗略分鏡，不是成品質量。

## 最終要實現

1. 1:1 正方形畫面，與第 1 幀相同構圖；畫面中只有角色，網站沒有其他功能。
2. **角色面部身份一致、鏡頭固定**。眼睛、鼻子、嘴巴、臉型與身體禁止產生因逐幀生成造成的抖動。眉眼需保持原設計。
3. 角色頭髮分成可獨立動畫的至少：前額瀏海、左右臉側髮絲、左右外層長髮、肩部髮尾、後髮。每束髮根受限，髮尾使用輕微彈性/慣性與不同相位的 wind model。
4. **眨眼**：雙眼自然地從開啟 → 半閉 → 完全閉 → 重新睜開，睫毛及眼皮位置穩定。不要通過將整張頭部縮放來假裝眨眼。
5. 耳環允許輕微受風擺動；項鏈和身體近乎固定。
6. 維持原始 anime 插畫質感，禁止 pixel art、馬賽克、3D 模型或整張圖片 CSS 左右平移來模擬髮絲。
7. 可以使用 React+Vite+TypeScript 和 Canvas/PixiJS/WebGL 變形網格。若有 Live2D/Spine/Rive 可用且合理，亦可選。素材如有缺少，應明確列出，不能假裝已完成精細分層。
8. 動畫以 requestAnimationFrame 驅動、deltaTime 更新、循環自然。注意視網膜屏幕清晰度、手機適配、減少動態偏好、效能及清理資源。
9. 原始素材不能破壞，開發生成的 masks、mesh、layers、js/timeline 請獨立存檔。
10. 需實際啟動頁面、對比原圖、截圖驗收並檢查眨眼及髮束的穿模；如果沒有瀏覽器工具則執行可用的自動化驗證並列出限制。

## 實施順序

先檢查每張圖片及 `10_frame_prompts.md`。確定哪些動態能使用**固定原圖＋局部變形**實現，哪些必須重建遮擋區域並補繪。優先製作一個身份穩定的高品質角色版本，再調整風與眨眼時間軸，最後驗收。

**嚴禁把十張不一致的 AI 圖片直接輪播，並將其冒充無縫角色動畫。** 十張只作 key pose guidance。以完全一致的角色模型和局部動態為最終完成標準。

完成後交付可以 npm install / npm run dev 運行的工程、素材來源/圖層說明、風力可調參數、眨眼時序、截圖/錄影及不足之處。
