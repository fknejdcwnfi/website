# 圓形視窗內持續流動的像素髮束

- 日期：2026-10-29
- 目前權威：使用者滿意既有眨眼，要求頭髮在眨眼的同時持續隨風飄柔、動作清楚且保持高更新率。
- 決策：[ADR-021](../decisions.md#adr-021--以圓形內可見髮段驗證持續飄柔)

> 本頁保存 PR #8 圓形內風動基線與當時數據。最新耦合髮束物理、反向採樣優化及文件式網站重構以[本輪指南](reference-rebuild.md)與 `artifacts/reference-rebuild/` 為準；本頁舊數字不作新版通過證據。

## 這次修正的問題

PR #7已分離12秒慢風與24秒眨眼時鐘，沒有輪末靜止區，但全畫布的發梢峰值不足以說明實際圓形展示。原本的根部權重讓可見中段移動較少，較大的髮尾位移又可能落在圓形裁切外；因此即使像素差分與時間軸檢查通過，觀看者仍可能主要注意到眨眼。

本輪以真正的圓形可見區檢查髮動：臉側發絲、外髮中段及肩前捲髮都需要參與，並在短時間內看得出柔和的層次。驗收將圓形內的風動像素、有效位移與眨眼區分開，不以裁切外的大峰值代替可見效果。

## 動作與像素契約

保留同一v4 canonical近景、八組髮束、17站C1空間曲線、獨立左右耳環與局部髮後修復。空間形變以根部固定的柔韌輪廓，把弧形彎曲帶到可見中段，再以分組差相及延遲讓髮梢跟隨；風場預先取樣，沒有整圖平移、旋轉或縮放。

| 時鐘 | 保留行為 |
| --- | --- |
| 風 | 12,000 ms持續循環，無輪末歸零包絡或重新啟動的彈簧 |
| 眨眼 | 24,000 ms獨立時鐘，4400／11300／20300 ms開始 |
| 單次眨眼 | 100 ms閉合、20 ms保持、160 ms重開，共280 ms |

使用者已接受的眨眼程式與節奏保持不變。眼事件期間頭髮及耳環繼續取樣；60／120／144／240 Hz只改更新密度，不改動作速度。正常0 ms可以是自然風中的一幀；pose1／10及減少動態提供完整canonical靜止，`wind=0`只停髮束／耳環而不停止獨立眨眼。

畫布仍為256²，另有192²／320²比較；固定42色、二值alpha與nearest-neighbor。臉、髮根、項鏈與固定身體不跟著頭髮位移。圓形、水平居中、無框及DPR實體像素對齊保持原展示規則，CSS圓形邊緣的抗鋸齒不等於畫布內部色彩平滑。原始 `assets/source/**`、凍結 `docs/reference/**`、canonical母版及九張runtime素材不因風動參數改寫。

## 驗證與證據

現行證據放在 `artifacts/flowing-hair/`。檢查除了固定區、髮根、色盤、alpha、補繪區、週期接縫及高Hz時鐘，也包含圓形內可見髮段、每段時間的持續變化，以及眨眼時仍有風動。桌機512及手機256 CSS像素的實際圓形視窗分別檢視，避免只看原始方形Canvas。

效能使用production建置、fresh單頁headless Chromium、1200×1000／DPR1、無CPU節流，先穩定再取樣完整12秒風週期；量測期間沒有截圖或其他瀏覽器工作。原生rAF與解除幀率限制的吞吐量分別記錄，GIF與指定時間截幀僅作視覺證據，不能當作實體高刷螢幕FPS。

原始Canvas、圓形預覽與量測都放在artifacts，不隨dist或首頁runtime下載。網站繼續載入少量材質作程序化渲染，不下載整套逐幀圖片。實際更新率仍受GPU、合成器、瀏覽器、OS及裝置能力影響，未測實體顯示器不宣稱已驗證。

### 圓形內可見風動

42項單元、型別、production build與素材／來源驗證通過。[肖像QA](../../artifacts/flowing-hair/qa.json) **58項通過**；[前版圓形基線](../../artifacts/flowing-hair/baseline-circle.json)以PR #7同一256²畫布、圓心(128,128)／半徑128取樣，排除眼區，保持睜眼以獨立比較髮動。

| 圓形內指標 | PR #7基線 | 本輪 |
| --- | ---: | ---: |
| 0→2秒風動像素差分 | 3204 | 5426 |
| 24個500 ms視窗的最小像素差分 | 258 | 669 |
| 24個2秒視窗的最小像素差分 | 1052 | 2030 |
| 左肩前捲髮中段峰值（y＜220） | 4.82 px | 6.99 px |
| 右側髮尾可見中段峰值（y＜220） | 3.46 px | 5.53 px |
| 左／右臉側髮峰值 | 0.81／1.00 px | 2.02／2.48 px |

八髮組及兩側耳環在圓形中均有實際像素參與。數值描述的是同一像素網格的變化與有效位移，不單獨代表主觀美感，也不是新增圖片數。前版已存在持續風動；本輪把更多弧形帶到看得見的中段，讓短時間內的動作更清楚。

27,519個保護像素與160個髮根保持固定，眼瞼差分仍限原眼區，所測髮後修復不透明區零內部破洞；42色與Canvas二值alpha維持不變。完整rig的lag／trail／wake跨週期取樣，接縫及100輪×13相位檢查通過；60／120／144／240 Hz模擬在共同時間點得到相同像素。已接受的眨眼相關程式與常量保持不變，眨眼時髮動繼續。

### Production效能

[本輪量測](../../artifacts/flowing-hair/performance.json)使用fresh單頁headless Chromium、1200×1000／DPR1、無CPU節流，先穩定2500 ms，再取樣完整12秒活動風週期，期間沒有截圖或其他瀏覽器工作。原生與不限幀模式均無超過50 ms長任務、正常頁面JS或HTTP錯誤。

| 排程 | 實際Canvas繪製與吞吐量 | callback CPU中位數／p95 |
| --- | --- | --- |
| 原生rAF | 721次／12.003秒，約60.07次／秒 | 3.8／5.6 ms |
| 解除Chromium幀率限制 | 2853次／12.002秒，約237.71次／秒 | 3.6／5.6 ms |

這輪以更清楚的圓形內髮動及原生約60次繪製／秒交付。不限幀值描述容器運算／繪製吞吐；實體120／144／240 Hz顯示器的合成與呈現成本仍需另行量測。
